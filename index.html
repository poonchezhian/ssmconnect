SSMConnect for Linux: update repository

The ssmconnect .rpm and .deb install the repository file for you, so new releases arrive with your system's normal updates. Download the first package from the Releases page, or add the repository by hand:

Fedora, RHEL, openSUSE (dnf)
sudo curl -o /etc/yum.repos.d/ssmconnect.repo https://poonchezhian.github.io/ssmconnect/ssmconnect.repo && sudo dnf install ssmconnect

Debian, Ubuntu (apt)
sudo curl -o /usr/share/keyrings/ssmconnect-archive-keyring.asc https://poonchezhian.github.io/ssmconnect/SIGNING-KEY.asc
echo -e "Types: deb\nURIs: https://poonchezhian.github.io/ssmconnect/deb/\nSuites: ./\nSigned-By: /usr/share/keyrings/ssmconnect-archive-keyring.asc" | sudo tee /etc/apt/sources.list.d/ssmconnect.sources
sudo apt update && sudo apt install ssmconnect

Older distributions (RHEL 8 and 9, Ubuntu 22.04, Debian 12, Linux Mint 21: GTK 4 / libadwaita too old for the packages above), Flatpak
flatpak install --user https://poonchezhian.github.io/ssmconnect/ssmconnect.flatpakref
Updates arrive with flatpak update.
